# Online Bookstore Database — SQL Project

## Project Overview
Designed and implemented a relational database 
for an Online Bookstore using PostgreSQL.

## Tools Used
- PostgreSQL
- pgAdmin

## Database Tables
- Books (Book_ID, Title, Author, Genre, Price, Stock)
- Customers (Customer_ID, Name, Email, City, Country)
- Orders (Order_ID, Customer_ID, Book_ID, Quantity, Amount)

## What I Did
- Designed relational database with foreign key constraints
- Imported data using PostgreSQL
- Written queries for data extraction and business insights
- Used JOINs, GROUP BY, HAVING for advanced analysis
